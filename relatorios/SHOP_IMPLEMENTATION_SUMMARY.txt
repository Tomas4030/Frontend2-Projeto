===============================================
ITEM STATE SYSTEM
===============================================

States Available:
┌──────────────┬──────────────┬─────────────┐
│ State        │ Can Buy?     │ Badge       │
├──────────────┼──────────────┼─────────────┤
│ available    │ Yes ✓        │ ✓ Disp.     │
│ limited      │ Yes ✓        │ ⏱ X/Y hoje │
│ exhausted    │ No ✕         │ ✕ Esgotado │
│ no_gold      │ No ✕         │ ⚠ Sem gold │
└──────────────┴──────────────┴─────────────┘

State Transitions (per day):
  none → available (first purchase of day)
       ↓
    limited (bought some, limit not reached)
       ↓
   exhausted (daily limit reached)
       ↓
    [Midnight Reset]
       ↓
  available (next day)

===============================================
REAL-TIME FEATURES
===============================================

Reset Timer:
- Displays in shop header
- Format: "5h 45m 23s"
- Updates every 1000ms (1 second)
- Shows exact time until midnight

Refresh Button:
- Reloads daily purchase counts
- Shows loading spinner while fetching
- Updates state badges immediately
- Location: Top-right of shop header

Alert Notifications:
- Shows after purchases
- Color varies: green (success), red (error), yellow (warning)
- Auto-dismisses after 3.5 seconds
- Uses shadcn/ui Alert component

===============================================
KEY FUNCTIONS
===============================================

getTimeUntilReset()
├─ Returns: { hours, minutes, seconds, totalMinutes, formatted }
├─ Example: "5h 45m 23s"
├─ Updates: Every second
└─ Use: Shop header countdown timer

getItemState(boughtToday, dailyLimit, hasGold)
├─ Returns: "available" | "limited" | "exhausted" | "no_gold"
├─ Determines: Can player buy this item?
└─ Use: Item card state determination

getStateInfo(state, boughtToday, dailyLimit)
├─ Returns: { label, color, bg, border, icon }
├─ Example: { label: "2/3 hoje", color: "text-yellow-400", ... }
└─ Use: Badge styling and text

formatRemainingLimit(boughtToday, dailyLimit)
├─ Returns: "X remaining" or "All available"
└─ Use: Descriptive text generation

===============================================
USAGE EXAMPLE
===============================================

// In ItemShop.tsx component:
const state: ItemState = getItemState(
  boughtToday,        // number (purchases today)
  item.dailyLimit,    // number | undefined
  hasGold             // boolean (gold >= cost)
);

const stateInfo = getStateInfo(
  state,
  boughtToday,
  item.dailyLimit
);

// Renders badge:
<span className={stateInfo.border + " " + stateInfo.bg}>
  {stateInfo.icon} {stateInfo.label}
</span>

// Example outputs:
// ✓ Disponível (green)
// ⏱ 2/3 hoje (yellow)  
// ✕ Esgotado (red)
// ⚠ Gold insuficiente (gray)
